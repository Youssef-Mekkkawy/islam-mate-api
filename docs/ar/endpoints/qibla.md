# القبلة

## نقطة النهاية

### GET /api/v1/qibla

الحصول على اتجاه القبلة والمسافة الى مكة المكرمة.

**المعاملات:**

| المعامل | النوع | مطلوب | الوصف |
|---|---|---|---|
| latitude | float | نعم | خط العرض |
| longitude | float | نعم | خط الطول |
| lang | string | لا | ar او en |

**مثال:**

```bash
curl "http://localhost:8000/api/v1/ar/qibla?latitude=30.04&longitude=31.23"
```

**الرد:**

```json
{
  "bearing": 134.5,
  "direction": "جنوب شرق",
  "distance_km": 1243.7,
  "location": {
    "latitude": 30.04,
    "longitude": 31.23
  }
}
```

---

## كيف يعمل

يتم حساب اتجاه القبلة باستخدام **معادلة الدائرة العظمى** — اقصر مسار بين نقطتين على كرة.

**إحداثيات الكعبة المشرفة:** 21.4225°N, 39.8262°E

الاتجاه يُقاس بالدرجات في اتجاه عقارب الساعة من الشمال:
- 0° = شمال
- 90° = شرق
- 180° = جنوب
- 270° = غرب
