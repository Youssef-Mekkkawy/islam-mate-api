# كيفية المساهمة

نرحب بمساهماتك في Islam Mate API!

## خطوات المساهمة

1. Fork المشروع على GitHub
2. انشئ branch جديد: `git checkout -b feature/اسم-الميزة`
3. اكتب الكود والاختبارات
4. تأكد من نجاح الاختبارات: `pytest tests/`
5. ارسل Pull Request

---

## انواع المساهمات

- اضافة وحدات جديدة
- تحسين البيانات الموجودة
- اصلاح الاخطاء
- تحسين التوثيق
- ترجمة المحتوى

---

## قواعد الكود

- استخدم Python 3.10+
- اتبع نمط BaseModule لكل وحدة جديدة
- اكتب اختبارات لكل endpoint جديد
- التوثيق بالعربية والانجليزية
